peach-sorbet

A small CSS kit with a soft look: a peach ground, pastel cards, blob-shaped covers and one purple accent. Two files, no build step.

This page is the kit's own shell: a sidebar on a wide screen, a floating tab bar on a phone. Resize it.

Tokens

Colour

core.css

Every colour, read off the stylesheet. Each swatch shows its light value on the left and its dark value on the right.

The six pastels

Tiles rotate through the first four; media cards through all six. In light mode three of the state tints equal a pastel; in dark mode they don't, so components read the state token.

Dialog and grid

designed

The native <dialog> dressed as a card; open it with showModal(). .grid is the auto-filling 300px grid the media grid and gallery already use.

Tinted

tint.css: colour from content. Four numbers on a card, set inline, and its surface, blob, meter, pill and primary button take that hue; on a bar's row or the dock, only the parts take it. The scheme keeps lightness and ink, so the same numbers work in dark.

The second file is optional. Turn it off to see what core.css does on its own: the pastel rotation, and purple wherever a tint was.

Hue and chroma

A vivid input gives a stronger blob and button; the card itself stays pastel. Under 0.03 the hue is dropped and the card is stone.

Any hue

--h, --c, --blob-c, --accent-c

The panel is always the surface colour.

Blob · Button · Ring

Twelve hues around the wheel

A category palette: the source app spread its twelve genres like this, with the chroma per family tuned by hand. Any set of categories can do the same.

From an image

Pick a picture. Its most vivid main colour becomes the card's hue, the way the source app reads album covers. Nothing leaves your browser.

The image is cut down to a few colours; each is scored by how much of the image it covers and how colourful it is, and near-white and near-black count for little.
